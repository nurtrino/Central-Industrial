Home Deliveries poller

Home Deliveries poller is a private, single-household tool. It reads the shipping notices that one dedicated Gmail mailbox receives, so the home's own automation system can tell the people who live there which packages are due to arrive.

What it does

Every few minutes the tool looks for new shipping and delivery emails in that one mailbox, works out what is arriving and when, and passes that to the home's automation system. It can only read mail; it cannot send, change or delete anything.

Who can use it

Only the household that runs it. It is not offered to the public and there is nothing to sign up for.

Privacy

How the tool handles Google account data is set out in the privacy policy.
